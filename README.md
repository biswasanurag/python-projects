# Python Projects

This repository contains a series of beginner-friendly Python projects that help practice core programming concepts through small, interactive applications.

## Projects

- [Project 1: PayUp!](./project-1/README.md) — A simple meal-splitting calculator.
- [Project 2: Jargon Jumble](./project-2/README.md) — A word scramble game using randomization and game logic.
- [Project 3: Sing Out](./project-3/README.md) — A karaoke queue manager built with lists and command-driven logic.
- [Project 4: National Parks Explorer](./project-4/README.md) — A data-driven park search app that works with JSON files and filtering.

## Learning Progression

These projects progress from basic Python fundamentals to more practical, data-handling applications:

- Input and output
- Variables and data types
- Arithmetic and calculations
- Conditionals and loops
- Lists, tuples, and dictionaries
- Functions and reusable code
- Working with files and JSON
- Command-line arguments and simple app logic

## How to Use

Open any project folder and read its README for the project overview and the Python concepts it introduces. Then run the Python scripts in that project folder to see the project in action.
