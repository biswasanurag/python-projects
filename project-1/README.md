# PayUp!

## Project Overview
PayUp! is a simple command-line calculator that helps a group split the cost of a meal. The program asks for the event name, meal name, total cost, service charge percentage, and group size, then calculates the final total and the amount each person should pay.

This project is a beginner-friendly way to practice using Python for everyday calculations and user input.

## Python Concepts Learned
- Variables for storing information such as cost, service charge, and group size
- `input()` to get data from the user
- Type conversion with `float()` and `int()`
- Basic arithmetic operations (`+`, `-`, `*`, `/`)
- Percentage calculation for service charges
- Formatting output using f-strings
- `:.2f` to display money with two decimal places
- Basic command-line program flow

## Example
The program might ask:
- What's the event name?
- What meal did you have?
- What was the cost of the meal?
- What was the service charge percentage?
- What was the group size?

Then it prints a breakdown like:
- Cost
- Service Charges
- Grand Total
- Split Amount per person
